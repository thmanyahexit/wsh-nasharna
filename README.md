# وش نشرنا هالأسبوع

ستوري أسبوعي (1080×1920) لقناة **مخرج ثمانية** يتحدّث تلقائيًا.

## كيف يشتغل
- كل خميس 6 مساءً يجيب حلقات آخر 7 أيام من القناة (بدون الشورتس) ويحدّث `episodes.json`.
- يصوّر الستوري ويحفظها في `story.png` — نزّلها وانشرها.
- التصميم يتكيّف مع عدد الحلقات: حلقة وحدة، ثنتين، ثلاث، أو شبكة لأكثر (حتى 6).

## المقاطع بدل الصور
ارفع مقطع الحلقة في مجلد `clips` باسم رقم الفيديو، مثل `clips/dQw4w9WgXcQ.mp4`.
الصفحة تعرض المقطع بدل الصورة تلقائيًا.

## تشغيل يدوي
تبويب **Actions** ← «تحديث ستوري الأسبوع» ← **Run workflow**.

## المعاينة
فعّل GitHub Pages من Settings ← Pages ← Branch: `main`، وافتح رابط الصفحة.
